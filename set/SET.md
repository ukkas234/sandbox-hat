## Why clothing is a texture, not a GLB (researched)

Source: official docs https://studio-docs.sandbox.game/avatars/how-to-paint-avatar-clothing.md
("How to paint avatar clothing") and
https://studio-docs.sandbox.game/avatars/how-to-create-an-avatar-accessory.md
("How to create an avatar accessory").

- **Clothing (Top/Bottom/Shoes) = a "skin": a set of 2D textures** painted in
  Avatar Studio onto the platform avatar. The deliverable is the painted
  texture PNG (1024×1024). Template layout, per the docs:
  - Top: front = upper half, back = lower half.
  - Bottom: front = left half, back = right half.
  - Shoes: upper shoe shape = right shoe, lower shoe shape = left shoe,
    soles are separate islands beside them.
- **Accessories (hat) = a 3D mesh (.glb)** on one socket — that is why the
  fedora is a GLB and the clothing is not.
- The template texture files are generated by Avatar Studio itself
  (Avatar Studio → Paint Skin → "Open Folder for Live Editing"). They are
  NOT downloadable. The garment footprints used here were reconstructed from
  the official template screenshots in the docs (copies in `templates/`).
- The docs' GitBook "ask" interface returned 403, so the exact numeric
  template resolution could not be confirmed that way; the Photoshop
  screenshots in the docs show the template canvas as **1024×1024**, and the
  textures here are built to that size.

## How to submit — steps ONLY the user can do in Avatar Studio

Clothing is made inside Avatar Studio (Sandbox Studio desktop app, or
https://create.sandbox.game/ → Avatar Studio). The textures here are the
paint; the user applies them. One skin per garment (only the garment you
paint is exported), so the 3 clothing items stay separate submissions.

For EACH of Top / Bottom / Footwear (repeat 3×, one garment at a time):
1. Avatar Studio → **Paint Skin** → name it (e.g. `MidnightGold_Top`) → Create.
2. Template: choose **Long Sleeves, Long Pants** (the coat + trousers cut).
3. **Paint** → **Open Folder for Live Editing**. This creates the template
   texture files on disk.
4. Replace ONLY that garment's texture file with the matching file from
   this folder (same filename as the template file — e.g. the Top texture
   replaces the Top template file). Leave the other two garments unpainted
   in this skin.
5. Check the live avatar preview: the charcoal+gold design should appear.
   If any detail lands in the wrong place, screenshot it and send it to
   waluh — the paint can be adjusted (the shoe layout is the least certain,
   see below).
6. **Export** → **Export Skin...** → you get a folder with the textures.
7. Publish at https://create.sandbox.game/projects (metadata + Silicon price).
8. Submit the Google Form (from https://luma.com/0ci3wufr?tk=Dq96pC) with
   the published asset link + Polygon wallet
   `0x0c7df522D735aDB453566F327823Bf204B226fEF`.

The hat (item 1) follows the accessory flow instead: Create Accessory →
import `sandbox-fedora.glb` → Hat socket → validate → Export → publish → form.
See `../submit-prompt.md`.

## Honest limits / what could not be verified

- **Template alignment is reconstructed, not byte-exact.** The real template
  files only exist inside Avatar Studio. The footprints here come from the
  docs' template screenshots, painted generously (bleed outside the garment
  islands is invisible in UV space). The Top and Bottom layouts are
  well-determined (simple front/back and left/right halves); the **Shoes
  layout is the least certain** (irregular U-shaped islands + separate
  soles) — verify it in the live Avatar Studio preview before exporting,
  and send a screenshot if it is off.
- **No live Avatar Studio check was possible from this VM** (no login, no
  submission made). The textures were validated as files only (valid PNG,
  1024×1024 RGB, sensible sizes) and visually on the Blender manikin.
- **One skin = one submission.** Do not paint all three garments in one
  skin and submit it as one item; make 3 separate skins.
- **Do not edit after submitting** — any edit = disqualification. If a
  texture needs fixing, fix it BEFORE publishing, or submit a new entry.
